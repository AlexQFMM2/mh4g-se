# MH4G 发掘装备高级自定义实施计划

## 目标与边界

本阶段在现有 MH3G 风格装备编辑界面中加入 MH4G 发掘装备高级自定义，不重做应用外壳。功能覆盖武器、防具和护石三类 28 字节记录，并始终以原始记录为基础做字段级补丁。

本阶段遵循以下固定原则：

1. 普通界面使用有说明的下拉预设，不要求用户直接理解十六进制代码。
2. 已知正常档和已知越界档分组显示；越界档使用红色警告，但不禁止选择和保存。
3. 每个一字节枚举字段均提供高级原始值 `00–FF`，未知原值必须可以原样保留。
4. 不检查装备是否能由游戏正常掉落，不校验技能、孔位、属性、斩味和强化组合是否合法。
5. 修改一个字段只改变它负责的字节或位，其他字节保持不变。
6. 发掘武器专用随机参数默认只对成品数据中 `is_relic=1` 的武器开放。
7. 普通武器不因打开或保存编辑器而改变高级字段；现有普通 ID 携带的自定义字节必须无损保留，并在原始记录视图中给出提示。

## 2026-08-10 实施状态

首个可测试版本已经完成以下内容：

- `equipment_lookups.csv` 运行时加载、显式发掘 ID 查询和独立数值换算层；
- 装备箱与武器编辑窗的“只看发掘武器”组合筛选；
- 发掘武器攻击、属性/异常、斩味代码、升级、专属值、孔数、稀有度、研磨要求和极限强化编辑；
- 武器三个装饰珠及固定标志、操虫棍猎虫等级/类型/八项实例值；
- 轻重弩 `0x01` 完整原值，以及 `bit5/bit3` 两个不覆盖其他位的待确认开关；
- 发掘防具防御、抗性、升级、孔数、稀有度、研磨和固定装饰珠编辑；
- 护石任意有符号技能点、未知技能 ID 无损保留和固定装饰珠编辑；
- 装备箱记录修改时按索引同步七份当前穿戴副本，覆盖 1500 格；
- 三份真实存档的字节级不修改往返、当前装备同步、数据覆盖和换算自动化测试。

斩味 `0x00–0x15` 七色长度已从 `mikewii/MH4U-Editor` 的 23 张内置斩味图反向并接入界面；MH4G `0xDA` 暂与其唯一红紫越界图对应，并明确标为待实机确认。攻击极限强化已按公开计算器的 `+20` 真攻击接入；发掘升级先使用明示的线性参考表。轻重弩 `bit5/bit3` 的最终中文含义仍属于下文“仍需反向确认”的研究项。

## 统一界面规则

### 档位与数值

攻击、属性、异常状态、防御等由存档代码查表得到实际数值的字段统一使用单行布局：

```text
档位选择：[0x14 - 正常档 ▼]    真实值：340    面板值：1632
```

固定列为：

```text
档位选择 | 真实值 | 面板值
```

- `档位选择`：显示代码、简短说明和正常/越界状态。
- `真实值`：游戏计算使用的基础值，例如大剑真攻击 340。
- `面板值`：按当前武器类型和武器自身字段换算的游戏装备面板值。
- 任一相关字段变化后，真实值和面板值必须立即刷新。
- 面板值只计算武器记录本身的攻击档、武器专属加成、升级和极限强化；不计入防具技能、护符/爪、猫饭、药物和任务内增益。
- 参考换算必须用 `※` 或“参考”明示，不伪装成已实机确认的数值。

高级原始值不另做十六进制大表格。用户选择“自定义原始值”后，在同一行出现两位十六进制输入框，右侧仍尝试显示可解释的真实值和面板值；无法解释时显示“未知”，但允许保存。

### 正常档与越界档

下拉框固定分为三组：

1. 正常游戏预设；
2. 已知越界/修改预设；
3. 自定义原始值 `00–FF`。

越界只作为说明，不是保存限制。读取到不在预设中的现有代码时，自动生成“保留原值 `0xNN`”选项，不得自动切换到默认值。

### 发掘武器筛选

装备箱和新建/编辑装备弹窗都必须提供发掘武器筛选，统一使用成品数据中的 `is_relic=1`，不通过中文/英文名称、颜色后缀或连续 ID 区间猜测。

装备箱工具栏增加：

```text
[ ] 只看发掘武器
```

- 勾选后只显示装备类型 7～20 且当前装备 ID 命中 `is_relic=1` 的非空格。
- 与页码、名称/ID 搜索、武器类型和“只显示非空格”等现有条件组合生效。
- 取消勾选后恢复原有筛选结果和当前页；筛选本身不得修改、移动或清空任何装备。
- 普通 ID 携带发掘参数的现存装备不归入该筛选，因为该选项筛的是“发掘武器外观/ID”，不是猜测记录是否合法。

新建/编辑装备弹窗在武器 ID 选择区域增加：

```text
[ ] 只看发掘武器
```

- 仅在装备类型为武器时启用；选择防具、护石或空记录时隐藏/禁用。
- 勾选后，武器名称/ID 下拉列表只包含当前武器类型中 `is_relic=1` 的记录，并继续支持名称和 ID 搜索。
- 新建装备时，筛选不得自动选择第一条或立即写入存档，必须等待用户明确选择并确认。
- 编辑普通武器时，即使勾选筛选，也要临时保留“当前普通武器（不属于发掘列表）”作为当前项，不能因列表过滤而悄悄替换装备 ID。
- 从发掘武器切换回普通武器后，发掘高级字段恢复只读，但已有原始字节仍保持不变。

## 第一部分：发掘武器

### 1. 武器记录字段

发掘武器高级面板解释以下字段：

| 偏移 | 字段 |
| ---: | --- |
| `0x01` | 操虫棍猎虫等级；轻重弩改造位；其他武器保留 |
| `0x04` | 属性/异常数值档 |
| `0x05` | 属性/异常类型 |
| `0x06–0x0B` | 三个装饰品记录 |
| `0x0C` | 近战斩味；轻重弩弹匣；弓瓶/箭种档 |
| `0x0D` | 攻击、会心、防御和偏移组合档 |
| `0x0E` | 发掘升级档 |
| `0x0F` | 武器专属值 |
| `0x10` | 未研磨、发光和孔数位组合 |
| `0x11` | 动态稀有度 |
| `0x12` | 研磨要求 |
| `0x13` | 极限强化 |
| `0x14–0x1B` | 操虫棍猎虫实例；其他武器保留 |

### 2. 攻击档与面板换算

已知正常攻击档覆盖真攻击 `110–340`，同时携带会心、防御和弩偏移组合。已知特殊档包括：

- 近战 `0x5B`：真攻击 355、防御 +100，要求与升级字段的组合另行提示；
- 远程 `0x1C`：真攻击 255、会心 +75%、防御 +25，要求与升级字段的组合另行提示。

面板值按武器显示倍率计算，首批换算表为：

| 武器 | 倍率 | 武器 | 倍率 |
| --- | ---: | --- | ---: |
| 大剑 | 4.8 | 片手剑 | 1.4 |
| 锤 | 5.2 | 长枪 | 2.3 |
| 轻弩 | 1.3 | 重弩 | 1.5 |
| 太刀 | 3.3 | 斩击斧 | 5.4 |
| 铳枪 | 2.3 | 弓 | 1.2 |
| 双剑 | 1.4 | 狩猎笛 | 5.2 |
| 操虫棍 | 3.1 | 盾斧 | 3.6 |

例如大剑特殊档真攻击 355 的基础面板为 `355 × 4.8 = 1704`。攻击极限强化按公开 MH4U 伤害计算器一致使用的 `+20` 真攻击计入。发掘升级 `0–3` 暂按 `+0/+10/+20/+30` 真攻击的线性规律作参考换算，UI 使用 `※` 明示；后续实机结果只需替换该独立表。武器专属 RAW、升级和攻击极限强化均在面板明细分项显示，避免重复计算。

UI 主行只显示“档位选择｜真实值｜面板值”；点击数值或帮助按钮后可以展开计算明细，例如基础真攻击、武器专属加成、极限强化和最终倍率。

### 3. 属性与异常状态

属性类型包括无、火、水、雷、龙、冰、毒、麻痹、睡眠和爆破。属性数值表按武器分为低、中、高三组：

- 低组：片手剑、弓、双剑、操虫棍；
- 中组：锤、长枪、太刀、斩击斧、铳枪、盾斧；
- 高组：大剑、狩猎笛；
- 轻重弩不使用该属性数值档。

正常元素档范围：

| 分组 | 最低可见 | 最高可见 | 最高觉醒 |
| --- | ---: | ---: | ---: |
| 低 | 90 | 370 | 400 |
| 中 | 120 | 500 | 540 |
| 高 | 180 | 750 | 810 |

正常异常状态档范围：

| 分组 | 最低可见 | 最高可见 | 最高觉醒 |
| --- | ---: | ---: | ---: |
| 低 | 100 | 220 | 240 |
| 中 | 140 | 300 | 320 |
| 高 | 210 | 450 | 480 |

参考修改器已经确认的越界档必须单独列出：

| 类型 | 低组 | 中组 | 高组 |
| --- | --- | --- | --- |
| 元素可见 | 1000 | 800 | 970 |
| 元素觉醒 | 21310 | 28420 | 42630 |
| 异常可见 | 1000 | 800 | 970 |
| 异常觉醒 | 19290 | 25720 | 38580 |

属性和异常状态不使用大剑等武器的攻击显示倍率。面板列显示武器自身属性；觉醒档显示“需觉醒”的数值。防具技能造成的属性/异常强化不在本阶段的武器自身面板值中计算。

### 4. 斩味

近战武器的 `0x0C` 是整条斩味方案的预设代码，不是红、橙、黄、绿、蓝、白、紫七个独立长度。正常图表代码为 `0x00–0x15`，另有越界/特殊代码 `0xDA`。

界面使用：

```text
斩味方案：[方案名称 / 代码 ▼]    [红][橙][黄][绿][蓝][白][紫]
```

要求：

1. 用户选择完整斩味方案，不提供七种颜色分别随意输入的普通控件。
2. 每个已解码方案显示七色条和各颜色长度；如游戏区分匠/斩味等级，再显示“基础”和“匠后”两条。
3. `0x00–0x15` 使用公开 `mikewii/MH4U-Editor` 内置图表的七色长度；每 5 点为一个最小单位，总长度为 450。
4. `0xDA` 暂显示为红 235、紫 215，并标注“推定映射，待实机确认”；一次实机查看即可确认或否定该映射。
5. 未知代码继续只显示原始值并允许无损保存，不虚构彩色长度。

### 5. 武器专属分支

在通用攻击、属性和斩味完成后，按武器类型逐项开放：

- 大剑、锤：RAW 加成；
- 片手剑、长枪：防御加成；
- 太刀、双剑：会心加成；
- 斩击斧、盾斧：瓶类型；
- 铳枪：炮击类型和等级；
- 狩猎笛：音色组合；
- 弓：瓶配置、蓄力和箭种；
- 操虫棍：猎虫等级、猎虫类型以及力量、耐力、速度、火、水、雷、冰、龙八项实例值；
- 轻重弩：弹匣、偏移、速射/蹲射、限制解除和配件位。

轻重弩的限制解除不能与 `0x13` 极限强化混为一个字段。未确认的位先以独立原始开关展示，并继续保持非目标位。

### 6. 极限强化与发掘选项

极限强化正常预设：

- `0x00`：无；
- `0x40`：攻击；
- `0x80`：防御；
- `0xC0`：生命/吸血。

读取到 `0xFF` 等值时显示“自定义原值”，允许原样保存。`0x10` 使用掩码分别修改未研磨、发光和孔数，绝不能重建整个字节而清除高四位。

## 第二部分：发掘防具

发掘防具高级面板覆盖：

- 防御档及实际防御值；
- 五属性抗性档及实际抗性值；
- 升级档、动态稀有度、研磨要求；
- 未研磨、发光、孔数；
- 三个装饰品 ID 和各自的 `bit 15` 固定/内置标志。

防具档位同样采用“档位选择｜真实值｜面板值”单行布局。防御和抗性映射未完全确认前，只显示代码和已确认值；不允许用猜测值填充。

显式发掘防具 ID 只用于标记和默认展开，不能成为保存限制。头部发掘 ID 表不完整，未命中列表的现存记录必须能原样保存。

“自定义技能孔位”通过装饰品 ID 与固定标志编辑，不把防具误解释成护石式技能 ID/点数字段。孔数和三个实际装饰品记录可以不一致，不进行合法性校验。

## 第三部分：护石高级自定义

护石类型固定为 6，不额外区分普通和发掘模式。高级面板覆盖：

- 护石等级/ID；
- 孔数；
- 技能 1 ID 和有符号 16 位点数；
- 技能 2 ID 和有符号 16 位点数；
- 三个 16 位装饰品记录及固定标志；
- `0x14–0x1B` 原始保留字节只读显示和原样保存。

技能点允许使用字段宽度内的任意有符号值，不限制正常掉落上限。未知技能 ID 显示为“未知技能 #ID（保留原值）”，不改写为无技能。

## 数据与程序结构

### 数据层

1. 扩展 `MH4GData` 和 Qt 数据适配器，加载 `data/<lang>/equipment_lookups.csv`。
2. 查询键固定使用 `domain + equipment_type + variant + value`。
3. 为正常、觉醒、越界和未知原值增加结构化标记，不能依赖名称字符串判断。
4. 新增斩味方案数据时记录七色长度、基础/匠后区别和证据来源。

### 计算层

建立不依赖 Qt 控件的数值换算模块，负责：

- 攻击档代码到真攻击、会心、防御和偏移；
- 武器真攻击到面板攻击；
- 武器专属加成、升级和极限强化的分项计算；
- 属性类型与武器分组选择；
- 属性/异常档代码到可见或觉醒数值；
- 斩味代码到七色方案。

所有换算函数必须既返回数值，也返回“已确认/越界/未知/待确认”状态，UI 不自行复制计算公式。

### 存档写回层

1. 为武器、防具、护石分别提供字段级补丁函数。
2. 所有位字段使用掩码更新。
3. 普通武器的高级字节默认只读并原样保存。
4. 当前装备副本与装备箱记录按已有差异处理规则同步，禁止无提示整条覆盖。
5. 支持撤销单次高级编辑，并在保存前显示被修改的字节和旧/新值。

## 实施顺序

1. 加载并查询 `equipment_lookups.csv`，建立独立换算模块和测试。
2. 在装备箱和新建/编辑弹窗中接入统一的 `is_relic=1` 发掘武器筛选。
3. 在现有武器编辑窗中加入发掘判定、正常/越界/原始值三组下拉框。
4. 完成攻击、属性、异常、升级、稀有度、研磨、孔数和极限强化。
5. 实现“档位选择｜真实值｜面板值”实时联动及计算明细。
6. 反向并验证斩味代码到七色长度，加入彩色斩味条。
7. 分类型实现瓶、炮击、笛音色、弓、轻重弩和操虫棍猎虫。
8. 实现发掘防具高级面板。
9. 实现护石高级面板。
10. 完成当前装备副本同步、批量导入导出和实机验证。

## 验收条件

- 发掘武器攻击行始终按“档位选择｜真实值｜面板值”显示并实时更新。
- 装备箱“只看发掘武器”和新建/编辑弹窗的同名筛选结果完全一致，并可与名称、ID 和武器类型筛选组合。
- 编辑普通武器时打开“只看发掘武器”不会自动替换当前装备 ID，也不会改变任何存档字节。
- 大剑真攻击 355 能显示基础面板 1704；其他 13 类武器倍率均有自动化测试。
- 正常属性档、觉醒档、已知越界档和未知原值可以区分并无损写回。
- `0xFF` 极限强化、猎虫全 `FF` 和未知斩味代码能打开、编辑其他字段并原样保存。
- 普通武器只进行基础编辑时，`0x04–0x05`、`0x0C–0x1B` 完全不变。
- `0x00–0x15` 均显示七色长度并有自动化测试；`0xDA` 显示红紫推定条和待实机确认标记；其他未知代码不显示虚构长度。
- 防具和护石不执行掉落合法性检查，任意字段宽度内的现存值不会被钳制或清零。
- 对三份真实存档执行单字段修改测试时，除目标字节/位和存档校验和外没有其他变化。
- 第 1401～1500 格和当前装备副本中的发掘装备均能完整编辑和重新加载。

## 仍需反向确认

- `0xDA` 红 235/紫 215 推定映射的单次实机确认，以及图表是否还需区分匠前/匠后；
- 发掘升级当前 `+0/+10/+20/+30` 参考表的实机精确确认（攻击极限强化 `+20` 已有公开计算器交叉参考）；
- 发掘防具防御档、抗性档的完整实际数值；
- 轻重弩 `0x01` 各位的限制解除和配件准确含义；
